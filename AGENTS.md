# Project rules

- Keep the quiz self-contained in `index.html`; do not add a server, external resources, or dependencies.
- Preserve the 10-question flow, progress tracking, score, feedback, results, and replay behavior.
- Use the existing `--cp-*` theme variables and preserve light/dark, responsive, and reduced-motion support.
- Keep interactions accessible with semantic controls, visible keyboard focus, and announced feedback.
- Open `index.html` directly in the integrated browser to check UI changes.
- Follow `.github/copilot-instructions.md` for detailed structure and behavior requirements.
